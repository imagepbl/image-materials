========================

Resource efficiency and circular economy measures for buildings (floorspace reduction, lifetime extension, lightweighting of material intensities) are implemented in :mod:`imagematerials.buildings.preprocessing.circular_economy_measures` and are enabled per-flag. See :doc:`../resource_efficiency_and_circular_economy` for a description of the flag-based configuration system shared across all sectors.
